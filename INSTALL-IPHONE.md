# Install on iPhone

1. Privately send the generated personalized setup URL to the student.
2. Open that link once in Safari on her iPhone. The setup fragment should disappear immediately and the assistant should open without a login or typed code.
3. Close Safari, open the ordinary production URL, and confirm the schedule still appears.
4. In Safari, tap **Share** → **Add to Home Screen** → **Add**.
5. Open **Etown Assistant** from the Home Screen.
6. Tap **Take me to class** or **Take me home** and choose **Allow While Using App** when iOS asks for location.

Do not bookmark or publicly share the personalized setup URL. After setup, use only the ordinary GitHub Pages URL.
