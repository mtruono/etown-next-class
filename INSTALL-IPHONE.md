# Use on iPhone

## Easiest option: just open the link

Send this link:

<https://mtruono.github.io/etown-next-class/>

Open it in Safari or Chrome. The schedule appears immediately. There is no login, setup code, account, or import step.

Tap **Campus guide** for a class when you want orientation. The iPhone will ask for location the first time. Choose **Allow While Using App** or the equivalent one-time permission. The guide stays inside Etown Next Class and does not open another map service.

## Optional: add it to the Home Screen

This is optional. It makes the site open with its own icon and app-like window.

1. Open <https://mtruono.github.io/etown-next-class/> in Safari.
2. Tap **Share**.
3. Tap **Add to Home Screen**.
4. Turn on **Open as Web App** if that choice appears.
5. Tap **Add**.
6. Launch **Next Class** from the new Home Screen icon.

Nothing else needs to be copied or pasted. The public link and Home Screen app show the same built-in schedule.

## First quick check

1. Confirm the expected next class, building, room, and time appear.
2. Tap its **Campus guide** button.
3. Allow location.
4. Confirm the in-app schematic shows the destination building and keeps the room visible.
5. Remember that the line is straight-line orientation, not a verified walking path.

The schedule and local schematic remain readable offline after the app shell has been cached. GPS availability and accuracy are controlled by the phone.
