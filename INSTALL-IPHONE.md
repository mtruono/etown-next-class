# Install on iPhone

Install the Home Screen app first, then import the setup code from inside that app. This avoids relying on Safari and the installed web app sharing the same local storage.

1. Open the deployed Etown Next Class URL in **Safari** on the iPhone.
2. Tap **Share**.
3. Tap **Add to Home Screen**. If it is not visible, use **Edit Actions** to add it.
4. Turn on **Open as Web App**.
5. Tap **Add**.
6. Launch **Next Class** from the new Home Screen icon.
7. Open the private `student-setup.txt` file on a trusted device or message, copy the entire code beginning with `ETOWN1.`, and paste it into the installed app.
8. Tap **Review setup code**. Read the term, courses, meeting count, date exceptions, buildings, rooms, and coordinate warnings.
9. Tap **Save schedule on this device** only if the preview is correct.
10. Leave **Etown Campus Map** selected as the preferred provider in Settings.
11. Tap a test **Directions** action.
12. Allow location for the Home Screen app. The app requests it only for that action and does not store it.
13. On the separate campus-map page, allow location if prompted, then use its location control to display the live blue dot.
14. Use **Apple Maps walking directions** or **Google Maps walking directions** if the campus route is not usable.

The room remains visible in the app's route handoff screen. The external map is expected to end at a building-level point, not at the classroom or a verified entrance. Return to Next Class to recheck the room.

If the app is offline, the imported schedule and next-class calculation remain available, but external maps require a connection.
