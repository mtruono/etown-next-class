# Engineering invariants

- Treat this product as a personal campus assistant centered on the next class, the time to leave, one-tap class navigation, and a permanent “Take me home” action for Founders B.
- Use the in-app outdoor campus navigator as the primary on-campus experience. It must show recognizable campus buildings, follow mapped walking paths rather than a straight line, provide accuracy-aware landmark/turn guidance, and track live position only while the student has explicitly started navigation. Keep Etown’s Concept3D map and Apple/Google Maps as visible fallbacks.
- Keep GitHub Pages as the application host. Do not migrate to Netlify or introduce a native wrapper, App Store release, login, password, account, typed setup code, paid map API, subscription, or paid custom domain.
- The owner has explicitly chosen a fully public schedule. The ordinary GitHub Pages URL must load the complete Fall 2026 timetable and Founders B-area home destination without a setup link, login, or local import.
- Never commit a student name, student ID, email address, dorm room number, generated setup code, `.ics` file, generated audit, private route-verification page, dashboard credential, or anything under `private/`. Course times, buildings, rooms, academic-calendar exceptions, and the Founders B-area destination are intentionally public.
- Never request location automatically. Request geolocation only after an explicit navigation-button tap. Live `watchPosition` is allowed only while the in-app directions view is active; stop it immediately on Back, arrival, visibility loss, or controller teardown.
- Exact-location check-ins are allowed only through a separate, explicit, student-controlled consent flow that defaults off. When enabled, send at most one captured point, accuracy, and server timestamp after a class/home navigation tap; never collect in the background. Keep a persistent, prominent sharing-on indicator plus pause and delete controls. Delete stored check-ins within 24 hours and never include course, room, destination, route, name, or contact details.
- Use one shared `NavigationTarget` flow for class and home navigation. Do not build a separate routing engine for Founders B.
- Treat Founders B as unverified until a real phone route is physically walked. Use honest labels such as “Founders Residence Hall · Founders B area” and never invent an entrance, indoor route, floor, stairs, hallway, accessible path, or left/right arrival instruction.
- Outdoor campus paths and turn instructions remain provisional until physically walked. Never call an unverified path safe, accessible, exact, or officially approved; keep a visible posted-signs and external-map fallback.
- Anonymous usage tracking is allowed only through a free Cloudflare Worker and free storage. It must remain technically and visibly separate from consent-based exact-location check-ins and must never collect GPS coordinates, accuracy, destination IDs, buildings, schedule contents, class names, course codes, rooms, student identity, full URLs, fragments, referrers, user-agent strings, free-form errors, or IP addresses in storage.
- Telemetry must be optional, transparent, failure-tolerant, and a no-op when no endpoint is configured. The student never authenticates; only the owner dashboard is protected.
- Preserve $0 operation. Stop rather than accept a payment method, paid plan, subscription, or paid upgrade.
- Treat official schedule and academic-calendar exceptions as centralized configuration, not scattered UI conditions. Use Eastern campus time through Temporal and inject `now` into deterministic logic.
- Preserve the PWA application shell, offline schedule access, configuration validation, storage utilities, route URL builders, accessibility, and test infrastructure. Remove private-link setup from the user-facing flow; legacy setup-fragment utilities may remain only if tests or migration compatibility still require them.
- Run `npm run check` before pushing. Run the phone-browser suite and Worker checks. Run privacy checks before and after production builds, and confirm ignored credentials and generated private artifacts remain untracked.
