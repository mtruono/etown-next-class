# Zero-dollar operating cost

The finished application can operate for **$0** under this design:

| Component              | Choice                                                 | Ongoing application cost |
| ---------------------- | ------------------------------------------------------ | -----------------------: |
| Source repository      | Public repository on GitHub Free                       |                       $0 |
| Hosting and TLS        | GitHub Pages project site                              |                       $0 |
| iPhone installation    | Safari Add to Home Screen                              |                       $0 |
| Application runtime    | Static HTML, CSS, and JavaScript                       |                       $0 |
| Schedule storage       | Browser local storage on the iPhone                    |                       $0 |
| Campus directions      | Documented links to the College's public Concept3D map |                       $0 |
| Alternative directions | Ordinary Apple Maps and Google Maps URLs               |                       $0 |
| Calendar companion     | Locally generated `.ics` file                          |                       $0 |
| Siri companion         | Manually created two-action Shortcut                   |                       $0 |

The app has no backend, database, custom domain, paid API key, map SDK, analytics, advertising, notification service, or Apple Developer Program dependency. Existing access to Codex is a development tool and is not counted as an application operating expense.

The $0 assumption depends on keeping the repository public and within GitHub's normal Pages and Actions policies. Adding a private repository requirement, custom domain purchase, paid API, server, push service, or native App Store distribution would change the cost model and is outside version one.
